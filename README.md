# AEM Workflow

Adobe Edge Delivery Services project based on the [AEM boilerplate](https://github.com/adobe/aem-boilerplate).

## Environments

- Preview: `https://main--{repo}--{owner}.aem.page/`
- Live: `https://main--{repo}--{owner}.aem.live/`

## Installation

```sh
npm install
```

## Linting

```sh
npm run lint
```

## Local development

1. Install the [AEM CLI](https://github.com/adobe/helix-cli): `npm install -g @adobe/aem-cli`
2. Start the AEM proxy: `aem up`
3. Open `http://localhost:3000` and begin developing.
